금리 추이

한국은행 ECOS 일별 시장금리(채권·CD는 금융투자협회 최종호가수익률)입니다. 기간을 짧게 잡으면 일별, 길게 잡으면 월평균이나 연평균으로 바꿔 보여줍니다.

기간 데이터

인포맥스 금리는 어디서 오나
KOFIA · 이 페이지의 기준

금융투자협회 최종호가수익률

매일 장 마감 후 지정 증권사들이 보고한 호가에서 극단값을 빼고 평균한 수익률입니다. 국고채, 통안채, 산금채, CD, 회사채의 대표 금리로 가장 널리 쓰이며, 한국은행 ECOS 시장금리도 이 값을 옮겨 씁니다.

민평 · 채권평가사 4사

민간 채권평가사 평균

KIS자산평가, 한국자산평가, NICE P&I, FN자산평가의 시가평가 수익률 평균입니다. 은행채·여전채·공사채 커브와 개별 종목은 대부분 이 값입니다. 이 페이지의 '회사채 AA- 민평'이 여기에 해당합니다.

KRX · 장내

국채전문유통시장 체결

한국거래소에서 실제 체결된 국고채 지표물 수익률입니다. 장중 실시간 국고채 금리는 대부분 여기서 나옵니다.

장외 · 체결과 호가

장외 거래 체결·중개 호가

금투협에 보고되는 장외 채권 체결 내역과 중개사 호가를 인포맥스가 모아 정리한 값입니다. 인포맥스식 가공 화면은 외부 API로 받을 수 없습니다.

금리 뉴스

연합인포맥스 채권/외환·정책/금융, 연합뉴스, 한국경제, Google 뉴스 검색에서 금리 관련 기사를 모읍니다. 평일 07~22시에 매시간 갱신되고, 이 화면은 10분마다 새 기사를 확인합니다.

기사 저작권은 각 언론사에 있습니다. 이 페이지는 제목, 매체가 RSS로 제공한 요약 앞부분, 원문 링크만 보여줍니다. 읽음 표시는 이 브라우저에만 저장됩니다. 단축키: j/k 또는 ↑/↓ 이동, Enter 원문 열기.

데이터: 한국은행 ECOS Open API 817Y002(시장금리 일별), 722Y001(기준금리). 뉴스: 각 언론사 RSS, Google 뉴스. GitHub Actions로 자동 수집.
